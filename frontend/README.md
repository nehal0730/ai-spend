
# AI Spend Frontend

Scaffolded Vite + React + TypeScript + Tailwind baseline.

Quick start

1. cd frontend
2. npm install
3. npm run dev

Install recommended dev tools and extra deps (includes react-query, tailwind plugins, ESLint):

```
npm install -D @tailwindcss/forms @tailwindcss/typography @typescript-eslint/parser @typescript-eslint/eslint-plugin eslint-config-prettier eslint-plugin-react eslint-plugin-react-hooks prettier eslint
```

Initialize shadcn/ui (interactive) after dependencies are installed:

```
npx shadcn-ui@latest init
```

Notes:
- The scaffold includes `ThemeProvider`, routing, and a starter `Layout`.
- Run `npm run typecheck` to validate types and `npm run lint` to run ESLint.
